Any auf einer Navigation wird zu EXISTS

    
Gesucht sind alle Events mit mindestens einer Show im Jahr 2024. Any prüft die Shows eines Events, bis es den ersten Treffer findet.

    

      
      
      
      
      
    

    

    

      
_db.Events

      

        
LINQ
_db.Events
  .Where(e => e.Shows.Any(s => s.Date.Year == 2024))
  .ToList()

        
SQL
SELECT e.* FROM Events AS e
WHERE EXISTS (
    SELECT 1 FROM Shows AS s
    WHERE s.EventId = e.Id
      AND strftime('%Y', s.Date) = '2024')
