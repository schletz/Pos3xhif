Mit AsciiDoc schreibst du technische Dokumentationen in einem einfachen Textformat.
Die Struktur ähnelt Markdown.
AsciiDoc kann aber mehr, zum Beispiel Querverweise, nummerierte Erklärungen im Code und ein Literaturverzeichnis.
*Asciidoctor* ist das Programm, das AsciiDoc-Dateien in HTML oder PDF umwandelt.
Für Windows gibt es kein Installationsprogramm.
Asciidoctor läuft daher in einem *Docker-Container*.
Das ist eine abgeschlossene Umgebung, in der alle nötigen Programme schon installiert sind.

[IMPORTANT]
Für den PDF-Export und für PlantUML-Diagramme in der Vorschau brauchst du eine lauffähige Installation von Docker.

== Extensions für VS Code installieren

Diese Extensions erleichtern dir die Arbeit mit AsciiDoc-Dateien in Visual Studio Code.
Installiere folgende Extensions:

- link:https://marketplace.visualstudio.com/items?itemName=asciidoctor.asciidoctor-vscode[Asciidoctor]
- link:https://marketplace.visualstudio.com/items?itemName=schletz.asciidoc-productivity[asciidoc-productivity]

Die Extension _asciidoc-productivity_ beschreibt das Kapitel link:{github_url}/07%20Asciidoctor/04_adoc_productivity.adoc[AsciiDoc Productivity Extension] ausführlich.

== Vorschau

Die Extension _asciidoc-productivity_ hat eine eigene Vorschau.
Du öffnest sie mit dem Symbol rechts oben im Editor.
Sie zeigt auch PlantUML-Diagramme und Formeln an und sieht dem fertigen PDF sehr ähnlich.

Möchtest du dein Dokument im Browser ansehen, installiere die Browser-Extension *Asciidoctor.js Live Preview*.
Du findest sie unter https://docs.asciidoctor.org/browser-extension/install/.

[NOTE]
Um lokale Dateien anzuzeigen, musst du der Browser-Extension in den Einstellungen das Recht *Zugriff auf Datei-URLs zulassen* geben.

== PDF erzeugen

Klicke im Explorer von VS Code mit der rechten Maustaste auf eine adoc-Datei.
Wähle *Export as PDF (requires docker)*.
Das PDF bekommt denselben Namen wie die adoc-Datei und liegt im selben Ordner.
Beim ersten Export erstellt die Extension ein Docker-Image.
Das dauert einige Minuten.
Danach geht der Export schnell.

Probiere es mit den Musterdateien aus.
Lade dazu die folgenden Dateien in einen gemeinsamen Ordner herunter.
Nutze in GitHub den Button *Download raw file*.

- link:{github_url}/07%20Asciidoctor/adoc%20demo.adoc[adoc demo.adoc]: der Text mit den Formatierungsanweisungen.
- link:{github_url}/07%20Asciidoctor/adoc%20demo.yml[adoc demo.yml]: das Layout für das PDF.
- link:{github_url}/07%20Asciidoctor/Example.cs[Example.cs]: Quellcode, den das Dokument mit `include` einbindet.

[NOTE]
GitHub zeigt adoc-Dateien direkt an.
Es unterstützt aber nicht alle Funktionen.
Für eine genaue Vorschau verwende daher VS Code oder das PDF.

=== Das Layout als YAML-Datei

Kopf- und Fußzeilen, Ränder und Schriftgrößen legst du in einer YAML-Datei fest.
Die Datei _adoc demo.yml_ beschreibt zum Beispiel die Fußzeile.
Liegt neben der adoc-Datei eine yml-Datei mit demselben Namen, fragt die Extension beim Export, ob sie dieses Layout verwenden soll.
Alle möglichen Einstellungen siehst du im link:https://github.com/asciidoctor/asciidoctor-pdf/blob/main/data/themes/default-theme.yml[Standard-Layout von asciidoctor-pdf].

== AsciiDoc mit einem KI-Agenten schreiben

Ein KI-Agent wie Claude Code kann AsciiDoc-Dokumente schreiben und selbst in ein PDF umwandeln.
Damit er die Regeln von AsciiDoc und den Weg zum PDF kennt, gibt es im Repo link:https://github.com/schletz/claude_settings[schletz/claude_settings] den Skill *asciidoc*.
Ein *Skill* ist eine Anleitung mit Skripten, die der Agent lädt, sobald er sie für eine Aufgabe braucht.

Der Skill enthält:

- Regeln für den Text, zum Beispiel genau einen Satz pro Zeile.
  So zeigt ein Diff in Git die Änderungen Satz für Satz.
- Eine Vorlage mit Codeblock und Callouts, Zitat, PlantUML-Diagramm, LaTeX-Formel, Bild und Literaturverzeichnis.
- Ein Python-Skript, das ein adoc-Dokument über Docker in ein PDF umwandelt.

Für die Installation brauchst du Node.js.
Der Befehl installiert den Skill global, also für alle deine Projekte:

[source,text]
----
npx skills@latest add schletz/claude_settings --skill asciidoc -g -y --copy
----

Das Skript für den PDF-Export braucht Python und das Paket `docker`.
Installiere es mit `pip install docker`.

Danach kannst du dem Agenten zum Beispiel schreiben: _„Erstelle aus kapitel.adoc ein PDF.“_
Er lädt den Skill selbst.
