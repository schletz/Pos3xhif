Wenn AsciiDoc bei dir läuft, kannst du auch deine *Diplomarbeit* damit schreiben.
AsciiDoc hat gegenüber Microsoft Word mehrere Vorteile:

* Es ist ein Textformat.
  Du kannst die Arbeit daher mit Git versionieren und auf GitHub stellen.
* Quelltexte werden automatisch formatiert.
  Mit _Callouts_ (nummerierten Markierungen im Code) erklärst du einzelne Zeilen.
* Die Teile der einzelnen Teammitglieder werden mit `include` automatisch zusammengefügt.
* Das Layout ist einheitlich, auch wenn mehrere Personen schreiben.

Lade das Paket *link:{github_url}/07%20Asciidoctor/diplomarbeit_asciidoc.zip[diplomarbeit_asciidoc.zip]* herunter.
Es enthält folgende Dateien:

Datei diplomarbeit_intro.docx::
Das ist die Vorlage der Schule für die ersten Seiten.
Sie enthält das Titelblatt, die eidesstattliche Erklärung und das Abstract auf Deutsch und Englisch.
Fülle sie aus und speichere sie als PDF mit dem Namen *diplomarbeit_intro.pdf*.
+
WARNING: Achte auf die Kopfzeile.
Die Abteilung steht auf der ersten Seite und separat auf den weiteren Seiten.
Achte auch auf das Schuljahr.

Datei diplomarbeit_gesamt.yml::
Das ist das Layout für das PDF.
Es erzeugt die Seitennummern in der Fußzeile.
Die Fußzeile enthält auch die Kapitelüberschrift, damit man sofort sieht, von wem der Inhalt ist.
+
.diplomarbeit_gesamt.yml
[source,yml]
----
extends: default
page:
  margin: [25mm, 20mm, 20mm, 20mm]
  numbering:
    start-at: toc
header:
  height: 25mm
  background-image: image:{header_image}[]
footer:
  recto:
    right:
      content: '*{chapter-title}* | {page-number} von {page-count}'
  verso:
    left:
      content: '{page-number} von {page-count} | *{chapter-title}*'
----

Datei diplomarbeit_gesamt.adoc::
Das ist die Gesamtdatei.
Sie lädt mit `include` die einzelnen Themenstellungen.
Beachte die Kommentare in dieser Datei.
+
TIP: Schließe die erzeugte Datei _diplomarbeit_gesamt.pdf_ mit einer _.gitignore_-Datei aus.
Sonst entstehen Merge-Konflikte.

Datei diplomarbeit_themenstellung.adoc::
Das ist die Vorlage für die individuellen Themenstellungen.
Kopiere sie am besten für jedes Teammitglied und füge den Nachnamen zum Dateinamen hinzu.

[TIP]
====
Benenne die Datei _diplomarbeit_themenstellung.adoc_ in _diplomarbeit_name1.adoc_, _diplomarbeit_name2.adoc_, ... um.
Binde sie in _diplomarbeit_gesamt.adoc_ mit `include` ein.
Erstelle für jedes Teammitglied einen Unterordner _assets_name1_, _assets_name2_, ... für Bilder und andere Dateien der Themenstellung.

Die adoc-Dateien der einzelnen Themenstellungen müssen im selben Ordner wie die Gesamtdatei liegen.
Sonst stimmen die Bildpfade nicht mehr.
====

== Das PDF erzeugen

Klicke im Explorer von VS Code mit der rechten Maustaste auf _diplomarbeit_gesamt.adoc_ und wähle *Export as PDF (requires docker)*.
Die Extension findet die Datei _diplomarbeit_gesamt.yml_ und fragt, ob sie dieses Layout verwenden soll.
Bestätige das.
Wie du die Extension installierst, steht im Kapitel link:{github_url}/07%20Asciidoctor/01_install.adoc[Verwendung von Asciidoctor unter Windows und macOS].

== Die Layoutdatei anpassen

Die Datei link:{github_url}/07%20Asciidoctor/diplomarbeit_gesamt.yml[diplomarbeit_gesamt.yml] legt das Grundlayout fest.
Auf link:https://github.com/asciidoctor/asciidoctor-pdf/blob/main/data/themes/default-theme.yml[der GitHub-Seite von asciidoctor-pdf] siehst du das Standard-Layout.
Du kannst alle diese Einstellungen in deiner yml-Datei überschreiben.

Möchtest du zum Beispiel die Überschriften etwas kleiner und Zitate in derselben Schriftgröße wie den Text haben?
Dann füge folgenden Block in _diplomarbeit_gesamt.yml_ ein:

[source,yml]
----
heading:
  part_break_before: always
  chapter_break_before: always
  # h1 is used for part titles (book doctype) or the doctitle (article doctype)
  h1_font_size: floor($base_font_size_large * 2)
  # h2 is used for chapter titles (book doctype only)
  h2_font_size: floor($base_font_size_large * 1.59)
  h3_font_size: round($base_font_size_large * 1.26)
  h4_font_size: $base_font_size_large
  h5_font_size: $base_font_size
  h6_font_size: $base_font_size_small
code:
  font_size: ceil($base_font_size * 0.8)
  line_height: 1.15
list:
  item_spacing: $vertical_rhythm / 6
table:
  cell_padding: 1.3
quote:
  font_size: $base_font_size
----
