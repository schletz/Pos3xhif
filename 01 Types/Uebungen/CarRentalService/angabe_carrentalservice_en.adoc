== Task: A vehicle rental

A rental company rents out motorcycles and cars.
For a motorcycle you pay a price per day.
For a car you also pay for every kilometer driven.
For every rental the system stores a rental record (_Rental_).
A rental is open until the vehicle is returned.

=== Class description

Create the private fields that you need for the implementation yourself.

==== Class Vehicle

The abstract base class for cars and motorcycles.
All properties are read-only.

* *LicencePlate* is the licence plate (number plate) of the vehicle.
* *PricePerDay* is the rental price for every day started.
* *Power* is the power of the vehicle in kW.
* The constructor is _protected_.
* *RequiredDrivingLicence* is an abstract property.
  It returns the driving licence category that you need for the vehicle.
* *CalculatePrice()* is an abstract method.
  It calculates the price from the rental days (_days_) and the kilometers driven (_kilometers_).

==== Class Motorcycle

All properties are read-only.

* *RequiredDrivingLicence* always returns _"A"_.
* *CalculatePrice()* calculates the price with the formula _days × PricePerDay_.
  The kilometers do not matter.

==== Class Car

All properties are read-only.

* *PricePerKm* is the price per kilometer driven.
* *Weight* is the weight in kg.
* *RequiredDrivingLicence* returns _"B"_ if the car weighs less than 3500 kg.
  Otherwise it returns _"C"_ (truck).
* *CalculatePrice()* calculates the price with the formula _days × PricePerDay + kilometers × PricePerKm_.

==== Class Customer

The class only stores the first name and the last name of the customer.
The constructor sets all properties.
All properties are read-only.

==== Class Rental

The class stores one rental.

* *Start*, *Customer*, *Vehicle* and *KilometersBegin* are set in the constructor and are read-only.
* *Start* is the beginning of the rental.
* *KilometersBegin* is the odometer reading at the beginning of the rental.
* *End* is the end of the rental.
  It is _null_ as long as the vehicle has not been returned.
  It is set from outside the class when the vehicle is returned.
* *KilometersEnd* is the odometer reading at the end of the rental.
  It is _null_ as long as the vehicle has not been returned.
  It is set from outside the class when the vehicle is returned.
* *RentedDays* is the number of days started and is read-only.
  If _End_ is _null_, _RentedDays_ is also _null_.
  A rental that ends on the same day lasts 1 day.
* *CalculatePrice()* calculates the price of the rental:
** If _End_ is _null_, the method returns 0.
** If _KilometersEnd_ is _null_, the method returns 0.
** Otherwise it returns the result of _CalculatePrice()_ of the rented vehicle.
   Pass _RentedDays_ and the kilometers driven (_KilometersEnd − KilometersBegin_) as arguments.

*Example:* A car with a _PricePerDay_ of 10 euros and a _PricePerKm_ of 5 euros is rented from 10 November 2021 to 15 November 2021.
The odometer reading is 100 km at the beginning and 200 km at the end.

* _RentedDays_ is 6 (10, 11, 12, 13, 14 and 15 November).
* _CalculatePrice()_ returns 6 × 10 + 100 × 5 = 560 euros.

[TIP]
====
* If you subtract 2 _DateTime_ values, you get a _TimeSpan_.
  You get the days started with this expression:
+
[source,csharp]
----
(int)(end - start).TotalDays + 1
----
* This only works with _DateTime_, not with _DateTime?_.
  So first check whether _End_ is _null_.
  After that you get the value with `End.Value`.
  The same applies to _KilometersEnd_.
* You write a _decimal_ literal with _M_ at the end, e.g. `0.5M`.
====

=== Tasks

Create every class in its own file.
You must *not* change the files _Program.cs_ and _TestHelpers.cs_.

_Program.cs_ is a test program.
It only compiles when all classes with all properties and methods from the model exist.
Also pay attention to the names of the constructor parameters, because the test program uses them (e.g. `pricePerDay: 10`).
So create all classes first.
Methods and properties that you have not implemented yet throw a _NotImplementedException_.
After that, start the program in the project _CarRentalService.Application_.
It shows _OK_ or _FAILED_ for every check.
If a check throws an exception, the check fails.
An exception outside of a check (e.g. when the test data is created) ends the program.

A complete solution shows _OK_ for all 43 checks.
At the end the program shows the points reached and the grade:

[source,text]
----
Result of the program in C:\...\CarRentalService.Application:
43 of 43 checks passed.
48 of 48 points. Grade: Sehr gut.
----
