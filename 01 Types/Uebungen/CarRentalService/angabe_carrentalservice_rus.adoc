== Указания к этому упражнению

Это упражнение показывает, как выглядят задание и тестовая программа на PLF.
PLF имеет такую же структуру: модель классов, описание классов и тестовая программа, которая начисляет баллы.

Скачайте файл _CarRentalService.7z_ из упражнений к главе _Types_.
Распакуйте файл и откройте файл _CarRentalService.sln_.

[NOTE]
====
На PLF вы найдёте solution на диске _Z_.
Там сначала впишите своё имя в файл _README.md_.
В этом упражнении, наоборот, файл _README.md_ содержит задание, и вписывать ничего не нужно.
====

== Задача: прокат транспортных средств

Пункт проката сдаёт в аренду мотоциклы и автомобили.
За мотоцикл вы платите цену за день.
За автомобиль вы дополнительно платите за каждый пройденный километр.
Для каждой аренды система сохраняет запись об аренде (_Rental_).
Аренда остаётся открытой, пока транспортное средство не вернут.

=== Описание классов

Приватные поля, которые нужны для реализации, создайте сами.

==== Класс Vehicle

Абстрактный базовый класс для автомобилей и мотоциклов.
Все properties доступны только для чтения (read-only).

* *LicencePlate* — номерной знак транспортного средства.
* *PricePerDay* — цена аренды за каждый начатый день.
* *Power* — мощность транспортного средства в кВт.
* Конструктор имеет модификатор _protected_.
* *RequiredDrivingLicence* — абстрактное property.
  Оно возвращает категорию водительского удостоверения, которая нужна для этого транспортного средства.
* *CalculatePrice()* — абстрактный метод.
  Он вычисляет цену по количеству дней аренды (_days_) и пройденным километрам (_kilometers_).

==== Класс Motorcycle

Все properties доступны только для чтения.

* *RequiredDrivingLicence* всегда возвращает _"A"_.
* *CalculatePrice()* вычисляет цену по формуле _days × PricePerDay_.
  Километры не учитываются.

==== Класс Car

Все properties доступны только для чтения.

* *PricePerKm* — цена за пройденный километр.
* *Weight* — масса в кг.
* *RequiredDrivingLicence* возвращает _"B"_, если автомобиль весит меньше 3500 кг.
  Иначе оно возвращает _"C"_ (грузовик).
* *CalculatePrice()* вычисляет цену по формуле _days × PricePerDay + kilometers × PricePerKm_.

==== Класс Customer

Класс хранит только имя и фамилию клиента.
Конструктор задаёт все properties.
Все properties доступны только для чтения.

==== Класс Rental

Класс хранит одну аренду.

* *Start*, *Customer*, *Vehicle* и *KilometersBegin* задаются в конструкторе и доступны только для чтения.
* *Start* — начало аренды.
* *KilometersBegin* — показание счётчика километров (пробег) в начале аренды.
* *End* — конец аренды.
  Значение равно _null_, пока транспортное средство не вернули.
  При возврате значение задают извне класса.
* *KilometersEnd* — показание счётчика километров в конце аренды.
  Значение равно _null_, пока транспортное средство не вернули.
  При возврате значение задают извне класса.
* *RentedDays* — количество начатых дней, доступно только для чтения.
  Если _End_ равно _null_, то и _RentedDays_ равно _null_.
  Аренда, которая заканчивается в тот же день, длится 1 день.
* *CalculatePrice()* вычисляет цену аренды:
** Если _End_ равно _null_, метод возвращает 0.
** Если _KilometersEnd_ равно _null_, метод возвращает 0.
** Иначе метод возвращает результат _CalculatePrice()_ арендованного транспортного средства.
   Передайте при этом _RentedDays_ и пройденные километры (_KilometersEnd − KilometersBegin_).

*Пример:* Автомобиль с _PricePerDay_ 10 евро и _PricePerKm_ 5 евро арендуют с 10.11.2021 по 15.11.2021.
Пробег в начале аренды — 100 км, в конце — 200 км.

* _RentedDays_ равно 6 (10, 11, 12, 13, 14 и 15 ноября).
* _CalculatePrice()_ возвращает 6 × 10 + 100 × 5 = 560 евро.

[TIP]
====
* Если вычесть одно значение _DateTime_ из другого, получится _TimeSpan_.
  Количество начатых дней даёт такое выражение:
+
[source,csharp]
----
(int)(end - start).TotalDays + 1
----
* Это работает только с _DateTime_, но не с _DateTime?_.
  Поэтому сначала проверьте, равно ли _End_ значению _null_.
  После этого значение можно получить через `End.Value`.
  То же самое относится к _KilometersEnd_.
* Литерал типа _decimal_ записывается с _M_ в конце, например `0.5M`.
====

=== Что нужно сделать

Создайте каждый класс в отдельном файле.
Файлы _Program.cs_ и _TestHelpers.cs_ изменять *нельзя*.

_Program.cs_ — тестовая программа.
Она компилируется только тогда, когда существуют все классы со всеми properties и методами из модели.
Обратите внимание и на имена параметров конструкторов, потому что тестовая программа их использует (например, `pricePerDay: 10`).
Поэтому сначала создайте все классы.
Методы и properties, которые вы ещё не реализовали, выбрасывают _NotImplementedException_.
Затем запустите программу в проекте _CarRentalService.Application_.
Для каждой проверки она показывает _OK_ или _FAILED_.
Если проверка выбрасывает исключение (exception), она считается не пройденной.
Исключение вне проверки (например, при создании тестовых данных) завершает программу.

Полное решение показывает _OK_ во всех 43 проверках.
В конце программа показывает набранные баллы и оценку:

[source,text]
----
Result of the program in C:\...\CarRentalService.Application:
43 of 43 checks passed.
48 of 48 points. Grade: Sehr gut.
----
